# Deploying CyberShield AI Security Simulator

Your application is a static HTML/CSS/JS file and can be easily deployed to be accessible to anyone on the web.

## Option 1: Netlify Drop (Easiest - No Account Required)

1. Go to **https://app.netlify.com/drop**
2. Drag and drop your `index.html` file (and `SPEC.md` if you want) onto the page
3. Your site will be deployed instantly with a unique URL
4. You can then customize the domain name in Netlify settings

## Option 2: GitHub Pages (Free - Recommended)

1. Create a GitHub account at **https://github.com**
2. Create a new repository (e.g., "cybershield-simulator")
3. Upload your `index.html` and `SPEC.md` files
4. Go to Repository Settings → Pages
5. Select "main" branch and click Save
6. Your site will be live at: `https://yourusername.github.io/cybershield-simulator/`

## Option 3: Vercel (Free)

1. Go to **https://vercel.com**
2. Sign up with GitHub
3. Click "Add New Project" → "Import Project"
4. Drag and drop your project folder
5. Deploy with one click

## Option 4: Cloudflare Pages (Free - Best Performance)

1. Go to **https://pages.cloudflare.com**
2. Sign up and create a new project
3. Connect your GitHub or upload directly
4. Get a free .pages.dev domain
