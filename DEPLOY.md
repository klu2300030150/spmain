s# Deploying CyberShield AI Security Simulator

## Quick Deploy - Works Instantly!

### Option 1: GitHub Pages (Recommended)

1. Go to your GitHub repository
2. Make sure `index.html` is in the root folder
3. Go to **Settings** → **Pages**
4. Under "Source", select **Deploy from a branch**
5. Branch: **main** (or master)
6. Folder: **/(root)**
7. Click **Save**
8. Wait 2-3 minutes and your site will be live!

### Option 2: Netlify Drop (Easiest)

1. Go to **https://app.netlify.com/drag-and-drop**
2. Drag your `index.html` file onto the page
3. Your site goes live instantly with a free URL!
